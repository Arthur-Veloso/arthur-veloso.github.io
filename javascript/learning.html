Setup & Debugging

INTEGRATION

Loading Scripts

For best performance, place scripts at the end of the <body> or use the defer attribute. This ensures non-blocking behavior so your page content loads first.

DEVTOOLS

The Console

Use console.log() to inspect variables. Access the browser console using Ctrl + Shift + i (Windows) or Cmd + Opt + i (Mac).

Variables & Types

JavaScript is loosely-typed, meaning you don't declare the data type explicitly. A single variable can hold different types over time.

Declaration

  • let: Use for values that will change (re-assignable).
  • const: Use for constant values (read-only).

Common Data Types

  • String: "Hello World"
  • Number: 42 or 9.99
  • Boolean: true or false
  • Null: null (Deliberate empty value)

Operations & Precedence

Arithmetic

JavaScript follows the standard order of operations: Division/Multiplication first, then Addition/Subtraction.

let total = (5 + 2) * 3; // 21

String Methods

Transform text using methods like .trim(), .slice(), or .toUpperCase(). Note: These methods return a new string and do not modify the original.

Modern Syntax

Template Literals

Combine variables and literals seamlessly using backticks and the ${} syntax.

const user = "John";
console.log(`Welcome back, ${user}!`);

Compound Assignment

The += operator adds the right-side value to the variable on the left and assigns the result back.

let score = 100;
score += 50; // New score is 150
